请你根据这些进展，总结成一个中文的报告，以 项目名称和日期 开头。报告应包含以下章节，但如果某个章节没有相关内容，则可以省略该章节：

1.  **新增功能**: 基于 Commits, Issues, PRs 和 Releases 中的信息，列出新增的主要功能和特性。
2.  **主要改进**: 基于 Commits, Issues, PRs 和 Releases，总结项目在性能、可用性、文档等方面的改进。
3.  **修复问题**: 列出已解决的 Bugs 和问题，主要参考 Issues 和 PRs，但也可能在 Release notes 中提及。
4.  **近期发布 (Recent Releases)**:
    *   列出近期的重要版本发布（通常会提供名称、标签、发布者和发布日期）。

请确保报告语言流畅，信息准确，重点突出。
